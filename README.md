# Mouza Dura Plot Ledger

Public, read-only page for the Mouza Dura joint layout (Tahasil Kanisi, Ganjam):
land sold and yet to be sold (sq ft and value at ₹800/sq ft), money still due from
MKR, and notes on each plot, shown on the layout map.

Page: https://venugopalmalapie-bit.github.io/mouza-dura-ledger/

## How to update
1. Download `ledger.xlsx` (button on the page, or from this repository).
2. Edit the blue cells on the **Plots** sheet (status, sq ft sold, paid to partners, notes).
   Payments not tied to a plot go on **Other payments**.
3. Upload the edited file here with the same name, `ledger.xlsx` (Add file → Upload files → Commit).
   The page reads the file directly, so it updates within a few minutes.
