How to update this page
  1. Click Download Excel to get the latest ledger.
  2. Edit the blue cells on the Plots sheet: status, sq ft sold, paid to partners, buyer, sale date, notes. Payments not tied to a plot go on Other payments.
  3. To check your changes before publishing, click Preview another Excel file and choose your edited file. Only you see the preview.
  4. Upload the file to the GitHub repository with the same name, ledger.xlsx (Add file → Upload files → Commit). The page updates for everyone within a few minutes.
